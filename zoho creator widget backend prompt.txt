API 1: ZOHO.CREATOR.UTIL.getInitParams()
═══════════════════════════════════════════════════════════════

PURPOSE: Get initialization parameters including logged-in user, app info, and brand color.
CALL AFTER: ZOHO.CREATOR.init()

── Code ──
ZOHO.CREATOR.UTIL.getInitParams().then(function(params) {
    console.log(params);
});

── Confirmed Response ──
{
  "scope": "zentegraindia",
  "envUrlFragment": "",
  "appLinkName": "client-support",
  "loginUser": "abhinand@zentegra.com",
  "themeBrandColor": "#5051F9"
}

── Field Details ──
scope            → string → Account owner / workspace name (used in API URLs)
envUrlFragment   → string → Environment URL fragment (empty = production)
appLinkName      → string → Current app's link name
loginUser        → string → Logged-in user's email address
themeBrandColor  → string → App brand color in hex format (e.g., "#5051F9")

── IMPORTANT NOTES ──
- loginUser returns EMAIL only, not full name or role
- To get user display name, split email: loginUser.split("@")[0]
- themeBrandColor is hex color string, use directly in CSS
- scope is required for building file download URLs
- This API does NOT return user role, profile, or permissions

   "Dropdown_Field": "Choice 1"

   TO SEND IN PAYLOAD: Use the ID value only (e.g., "Lookup_Pricing": "26683000001080476")

   "Image_Field": "/api/v2.1/zentegraindia/client-support/report/Widget_Test_Report/266830000010804772/Image_Field/download?filepath=...png"
   - Single string (not array)
   - To display: prepend base URL of your DC (e.g., "https://creatorapp.zoho.in")
   - URL pattern: /api/v2.1/{scope}/{app}/report/{report}/{recordId}/{fieldName}/download?filepath={path}

9. FILE UPLOAD FIELD → returns as ARRAY of strings
   "File_Field": [
     "/api/v2.1/.../File_Field/download?filepath=...gif",
     "/api/v2.1/.../File_Field/download?filepath=...jpg"

   - Each element is a relative download URL path
   - Filename can be extracted from filepath parameter value

    Notes field data does NOT appear in getRecordById or getRecords responses.

11. EMPTY/NULL FIELDS → COMPLETELY OMITTED from response
    Fields with no value are NOT returned as null or "".
    They simply don't appear in the data object.
    MUST use: record.Field_Name || "" or record.Field_Name || null for safety

12. SYSTEM FIELDS → NOT returned by default
    Added_Time, Modified_Time, Added_User are NOT included in Widget SDK responses.
    These are only available via REST API v2.

API 6: ZOHO.CREATOR.DATA.getRecords()
═══════════════════════════════════════════════════════════════

PURPOSE: Fetch multiple records from a report.

── Config ──
{
    app_name: "client-support",
    report_name: "Widget_Test_Report",
    page: 1,                                    // Page number (1-based)
    pageSize: 200,                               // Records per page (max 200)
    criteria: '(Field == "value")'               // Optional filter criteria
}

── Code (without criteria) ──
ZOHO.CREATOR.DATA.getRecords({
    app_name: "client-support",
    report_name: "Widget_Test_Report",
    page: 1,
    pageSize: 200
}).then(function(response) {
    var records = response.data;
    console.log("Total records:", records.length);
}).catch(function(err) {
    console.log("Error:", err);
});

── Code (with criteria) ──
ZOHO.CREATOR.DATA.getRecords({
    app_name: "client-support",
    report_name: "Widget_Test_Report",
    criteria: '(Dropdown_Field == "Choice 1")',
    page: 1,
    pageSize: 200
}).then(function(response) {
    console.log(response);
});

── Confirmed Response (records found) ──
{
  "code": 3000,
  "data": [
    {
      "ID": "266830000010804772",
      "Single_Line": "test",
      "Multi_Line": "test",
      ... (same field structure as getRecordById)
    }
  ]
}

── Response Structure ──
- code: 3000 (success)
- data: ARRAY of record objects (not single object)
- NO pagination info returned (no "info", "more_records", etc.)

── ERROR Response (no records match criteria) ──
THROWS ERROR (does NOT return empty array!)
{
  "status": 400,
  "statusText": "",
  "responseText": "{\"code\":9280,\"message\":\"No records found matching the given criteria. Try using a different search criteria.\"}"
}

── CRITICAL NOTES ──
1. DIFFERENCE FROM getRecordById: data is ARRAY [...] not OBJECT {...}
2. NO PAGINATION INFO is returned by Widget SDK (unlike REST API v2)
3. To check for more records: compare data.length with pageSize
   - If data.length === pageSize → more records may exist → fetch next page
   - If data.length < pageSize → no more records
4. When NO records match: SDK throws ERROR with code 9280 (HTTP 400)
   - Does NOT return { code: 3000, data: [] }
   - MUST handle in .catch() block
5. Criteria format: wrap in parentheses '(Field == "value")'

── Error Handling Pattern ──
ZOHO.CREATOR.DATA.getRecords(config)
  .then(function(response) {
      var records = response.data;
      // Process records
  })
  .catch(function(err) {
      if (err.responseText) {
          var parsed = JSON.parse(err.responseText);
          if (parsed.code === 9280) {
              // No records found — treat as empty list
              var records = [];
          } else {
              // Real error
              console.error(parsed.message);
          }
      }
  });

        }

  },

- code: 3000 (success)
- data: object with only "ID" of newly created record
- message: success message string

── PAYLOAD RULES ──
1. Text fields: send as string
   "Single_Line": "value"

2. Number fields: send as number (SDK converts to string internally)
   "Number_Field": 50
   "Decimal_Field": 25.5

3. Date fields: send as formatted string matching app date format
   "Date_Field": "20-Jun-2026"     → dd-MMM-yyyy format

4. Single choice fields: send selected value as string
   "Dropdown_Field": "Choice 2"
   "Radio_Field": "Choice 1"

5. Multi choice fields: send as array of strings
   "Multi_Select_Field": ["Choice 1", "Choice 2"]

6. Checkbox (decision box): send as boolean
   "Checkbox_Field": true

7. Checkbox (multi choice): send as array
   "Checkbox_Field": ["Choice 1", "Choice 3"]

8. Lookup fields: send the ID of the linked record as string
   "Lookup_Pricing": "26683000001080476"

── CRITICAL NOTES ──
1. Uses form_name NOT report_name (unlike get/update/delete)
2. Function name is addRecords (PLURAL) even for single record
3. Payload must be wrapped: { payload: { data: {...} } }
4. Only returns the new record's ID, not the full record data
5. message comes from form's success message configuration

═══════════════════════════════════════════════════════════════
CRITERIA SYNTAX RULES
═══════════════════════════════════════════════════════════════

1. ALWAYS wrap criteria in parentheses:
   ✅ '(Status == "Active")'
   ❌ 'Status == "Active"'

2. String values use double quotes inside single-quoted string:
   '(Field == "value")'

3. Number values — no quotes:
   '(Number_Field == 100)'

4. AND/OR conditions:
   '(Status == "Active" && Priority == "High")'
   '(Status == "Active" || Status == "Pending")'

5. Not Equal:
   '(Status != "Closed")'

6. Contains:
   '(Name.contains("John"))'

7. Starts With:
   '(Name.startsWith("Jo"))'

8. ID comparison:
   '(ID == 266830000010804772)'

── Pattern 1: Safe Field Access (handle missing/empty fields) ──

function getFieldValue(record, fieldName, defaultValue) {
    var val = record[fieldName];
    if (val === undefined || val === null) return defaultValue || "";
    return val;
}

function getNumberField(record, fieldName) {
    var val = record[fieldName];
    if (val === undefined || val === null) return 0;
    return parseFloat(val) || 0;
}

function getLookupDisplay(record, fieldName) {
    var val = record[fieldName];
    if (!val || typeof val !== "object") return "";
    return val.zc_display_value || "";
}

function getLookupId(record, fieldName) {
    var val = record[fieldName];
    if (!val || typeof val !== "object") return "";
    return val.ID || "";
}

function getUrlValue(record, fieldName) {
    var val = record[fieldName];
    if (!val) return "";
    if (typeof val === "object") return val.url || "";
    return val;
}

── Pattern 2: Fetch All Records with Pagination ──

async function fetchAllRecords(appName, reportName, criteria) {
    var allRecords = [];
    var page = 1;
    var pageSize = 200;
    var hasMore = true;

    while (hasMore) {
        try {
            var config = {
                app_name: appName,
                report_name: reportName,
                page: page,
                pageSize: pageSize
            };
            if (criteria) config.criteria = criteria;

            var response = await ZOHO.CREATOR.DATA.getRecords(config);
            var records = response.data || [];
            allRecords = allRecords.concat(records);

            if (records.length < pageSize) {
                hasMore = false;
            } else {
                page++;
            }
        } catch (err) {
            // Code 9280 = no records found
            if (err.responseText) {
                var parsed = JSON.parse(err.responseText);
                if (parsed.code === 9280) {
                    hasMore = false;
                } else {
                    throw err;
                }
            } else {
                throw err;
            }
        }
    }

    return allRecords;
}

── Pattern 3: CRUD Operations Wrapper ──

var CreatorAPI = {
    init: function() {
        return ZOHO.CREATOR.init();
    },

    getInitParams: function() {
        return ZOHO.CREATOR.UTIL.getInitParams();
    },

    getRecord: function(appName, reportName, id) {
        return ZOHO.CREATOR.DATA.getRecordById({
            app_name: appName,
            report_name: reportName,
            id: String(id)
        });
    },

    getRecords: function(appName, reportName, criteria, page, pageSize) {
        var config = {
            app_name: appName,
            report_name: reportName,
            page: page || 1,
            pageSize: pageSize || 200
        };
        if (criteria) config.criteria = criteria;
        return ZOHO.CREATOR.DATA.getRecords(config);
    },

    addRecord: function(appName, formName, data) {
        return ZOHO.CREATOR.DATA.addRecords({
            app_name: appName,
            form_name: formName,
            payload: { data: data }
        });
    },

    updateRecord: function(appName, reportName, id, data) {
        return ZOHO.CREATOR.DATA.updateRecordById({
            app_name: appName,
            report_name: reportName,
            id: String(id),
            payload: { data: data }
        });
    },

    deleteRecord: function(appName, reportName, id) {
        return ZOHO.CREATOR.DATA.deleteRecordById({
            app_name: appName,
            report_name: reportName,
            id: String(id)
        });
    },

    getCount: function(appName, reportName) {
        return ZOHO.CREATOR.DATA.getRecordCount({
            app_name: appName,
            report_name: reportName
        }).then(function(r) {
            return parseInt(r.result.records_count) || 0;
        });
    },

    getForms: function(appName) {
        return ZOHO.CREATOR.META.getForms({ app_name: appName });
    },

    getReports: function(appName) {
        return ZOHO.CREATOR.META.getReports({ app_name: appName });
    },

    getFields: function(appName, formName) {
        return ZOHO.CREATOR.META.getFields({
            app_name: appName,
            form_name: formName
        });
    }
};

  ZOHO.CREATOR.DATA.addRecords({app_name, form_name, payload:{data:{...}}})

UPDATE:
  ZOHO.CREATOR.DATA.updateRecordById({app_name, report_name, id, payload:{data:{...}}})
  ZOHO.CREATOR.DATA.updateRecords({app_name, report_name, criteria, payload:{data:{...}}})

DELETE:
  ZOHO.CREATOR.DATA.deleteRecordById({app_name, report_name, id})
  ZOHO.CREATOR.DATA.deleteRecords({app_name, report_name, criteria})

META:
  ZOHO.CREATOR.META.getForms({app_name})

NAVIGATE:
  ZOHO.CREATOR.UTIL.navigateParentURL({url, window:"same"|"new"})

REMEMBER:
  - addRecords uses FORM_NAME, everything else uses REPORT_NAME
  - All number fields return as STRINGS — always parse
  - Empty fields are OMITTED from response (not null)
  - No records found = ERROR (code 9280), not empty array
  - Lookup fields: always use .zc_display_value for display
  - URL fields return object: {value, url}
  - File fields return array of relative URL strings
  - Image fields return single relative URL string
  - Criteria must be in parentheses: '(Field == "value")'
  - getRecordCount returns under "result" key (not "data")
  - records_count is a STRING, must parseInt()
